변조별 전형 PAR

          

        

        

          PAR 를 잘못 잡으면
          · 너무 작게 → 피크가 ADC 상한 초과 → 클리핑 → EVM 악화, 파워 낮게 측정
          · 너무 크게 → ADC 동적범위 낭비 → 측정 SNR 저하 → EVM 바닥값 상승
          실측 PAR (Peak − Power) 를 재서 설정값과 1~2 dB 안에 있는지 확인하는 것이 가장 확실하다.
        

      

    

  



  
  

    

      

        
파일 선택

        

        

          
          
          
        


        

          파일은 어디로도 전송되지 않는다
          브라우저 안에서 헤더 앞부분만 잘라 읽는다. 수백 MB 파일도 즉시 처리되고 IQ 데이터는 건드리지 않는다.
        

        

          값이 없을 때
          N/A 그 규격에는 있는 항목인데 헤더에 기록이 없다 (구형 펌웨어가 안 남긴 경우)
          XXX 그 규격·모듈에 애초에 해당 없는 항목 (11ac 파일의 HE 항목, WLAN 파일의 BT 항목 등)
          값이 하나라도 있으면 언제나 값을 그대로 보여준다.
        

        

          표시 항목 (11그룹 165개)
          파일 · 신호 · WLAN 공통 · HE/EHT · DSSS/CCK
          필터/윈도우 · 패킷 · MAC 헤더
          Degradation(WaveGen GUI 순서) · Bluetooth · UWB
        

        

          비교 모드
          다른 값은 노란 배경으로 표시하고, 그룹 머리에 차이 개수를 붙인다.
          목록에서 클릭 = A, Shift+클릭 = B.
          원본 SCPI 차이 버튼은 위 164개 밖의 명령까지 전부 비교한다.
        

        

          N/A 가 정상인 경우
          WaveGen GUI 의 Phase Noise · AWGN SNR · IQ Gain/Phase/Delay · DCI/DCQ · SFactor · Channel Gain/Phase 는 생성 시점에만 적용되고 .iqvsg 헤더에 저장되지 않는다.
          2008~2012 년 .mod 변환 BT 파일에는 ModuleConfiguration 자체가 없다.

장비

        

          

            
            
          

          

            
            
          

        

        

          
          
        

        

          
          확인 전
        

        
PC 프로그램 — 장비에 직접 연결중계 프로그램 없이 이 프로그램이 장비(SCPI TCP)에 바로 붙는다 (CAST 와 같은 방식).

        

        

        
중계 프로그램 — 휴대폰 · 웹 브라우저용

        

          
          
        

        

          
          
          확인 전
        

        

          중계 프로그램이 켜져 있어야 동작한다
          브라우저는 장비 소켓에 직접 붙지 못하므로 같은 폴더의 rf_bridge.py 가 대신 연결한다.
          · PC: RF중계.exe 실행 (또는 [중계 실행]) → 마지막에 쓴 장비에 연결해 두고 이 계산기가 열린다. Python 필요 없음
          · [중계 실행] 은 RF중계.exe 를 한 번이라도 실행한 PC 에서 동작한다 (그때 rfbridge:// 주소가 등록됨)
          · 휴대폰: PC 에서 「RF 중계 (휴대폰도 연결)」 실행 → 중계 창에 나온 http://PC-IP:8765 를 휴대폰 브라우저로 연다 (같은 Wi-Fi · 사내망)
          · 휴대폰은 꼭 그 주소로 연다 — github 주소(https)에서는 휴대폰 브라우저가 PC(http) 로 보내는 요청을 막는다
        

        


        

          포트
          LitePoint IQxel 계열은 보통 24000, Keysight · R&S 는 보통 5025. 장비 설정에서 확인.
