변조별 전형 PAR

          

        

        

          PAR 를 잘못 잡으면
          · 너무 작게 → 피크가 ADC 상한 초과 → 클리핑 → EVM 악화, 파워 낮게 측정
          · 너무 크게 → ADC 동적범위 낭비 → 측정 SNR 저하 → EVM 바닥값 상승
          실측 PAR (Peak − Power) 를 재서 설정값과 1~2 dB 안에 있는지 확인하는 것이 가장 확실하다.

          확인 전
        

        
PC 프로그램 — 장비에 직접 연결중계 프로그램 없이 이 프로그램이 장비(SCPI TCP)에 바로 붙는다 (CAST 와 같은 방식).

        

        

        
중계 프로그램 — 휴대폰 · 웹 브라우저용

        

          
          
        

        

          
          
          확인 전
        

        

          중계 프로그램이 켜져 있어야 동작한다
          브라우저는 장비 소켓에 직접 붙지 못하므로 같은 폴더의 rf_bridge.py 가 대신 연결한다.
          · PC: RF중계.exe 실행 (또는 [중계 실행]) → 마지막에 쓴 장비에 연결해 두고 이 계산기가 열린다. Python 필요 없음
          · [중계 실행] 은 RF중계.exe 를 한 번이라도 실행한 PC 에서 동작한다 (그때 rfbridge:// 주소가 등록됨)
          · 안드로이드폰: RF 중계 앱 설치 → 앱 실행 (또는 [중계 실행]) → 중계 주소는 http://localhost:8765 그대로. PC 필요 없음, 폰이 테스터와 같은 Wi-Fi 에 있어야 함
          · 앱 없이 휴대폰: PC 에서 「RF 중계 (휴대폰도 연결)」 실행 → 중계 창에 나온 http://PC-IP:8765 를 휴대폰 브라우저로 연다 (github 주소에서는 PC 로 가는 요청이 막힘)
        

        


        

          포트
          LitePoint IQxel 계열은 보통 24000, Keysight · R&S 는 보통 5025. 장비 설정에서 확인.

CRiPL 사용법  · Since 2026-11-27

      
CRiPL (Crezon Product information List) — LitePoint(LP) · Photonics(QP) 제품의 본체 · 지원 규격 · 옵션을 찾고, 필요한 품목을 골라 목록으로 정리하는 사내 페이지. 정보는 Salesforce 포털 기준으로 매월 1일 · 15일 업데이트한다.

      
아래 항목 제목을 누르면 펼쳐진다.

지원공용 아이디지원 암호제품 · 옵션 (가격 없음)

        
관리자관리자 이메일관리자 암호영업 전부 + 최신 업데이트 · 계정 관리

      
    
        
  • 이 기기에서 7일 동안 로그인 유지를 켜 두면 같은 기기에서는 다시 묻지 않는다. 공용 PC 에서는 끄고 쓸 것.

    폰은 두 손가락으로 벌리기 / 좁히기로도 크기를 바꾼다. − / + 버튼은 작게 줄여도 누를 수 있는 크기로 남는다. 크기는 기기마다 기억.

2 LP 제품 찾기

      
    
        
  1. 제품 라인을 고른다 — 첫 화면 카드의 품목 N개 보기 또는 위쪽 제품 라인 콤보.
    2. 
        
  2. ① 제품(본체) 선택에서 본체의 ◉ 보기를 누른다. 본체는 모델 · 포트 순 (예: M2X → M8X → M16X).
          
    → 그 본체가 선택 목록에 자동으로 담긴다. 다른 본체로 바꾸면 묻지 않고 선택 목록을 비우고 새로 시작한다.
    3. 
        
  3. 바로 아래에 지원 규격 카드와 ② 그 본체에 붙는 품목(HW 기능 추가 · SW 기능 추가 · 서비스)이 나온다. 표 제목 줄의 접기 ▲ / 펼치기 ▼로 표마다 접을 수 있다.
    4. 
      

      
조건으로 거르기 — 표준 규격 · 최고 주파수 · 신호 대역폭 · RF 포트 수 · MIMO 를 넣으면 조건에 맞는 라인 · 본체만 남는다 (안 맞는 라인은 첫 화면에서 빠짐).

      
✔ 조건 맞음✕ 조건 불일치: 포트 8본체 줄 — 초록 = 맞음, 빨강 = 안 맞음

      
    
        
  • 제품 선택 · 조건 지우기 — 라인 · 본체 · 조건을 한 번에 지운다.
    • 
        
  • 제품 선택 칸 오른쪽 접기 ▲ — 접으면 지금 걸린 조건만 한 줄로 남는다 (예: 조건: 제품 라인 IQxel-MW).
    • 
        
  • 표 위 체크: 기본 설명 · 상세 설명(포털 영문 설명) · 구분 보기 · Part No 보기
    • 
      

      
첫 화면 카드 표시

      
선택 2업데이트 2 ▾포털 신규 1 ▾단종 1 ▾본체 6 · SW 33 · 액세서리 3UG 33체험 1

      
    
        
  • 선택 N = 선택 목록에 담긴 그 라인 품목 수 · 업데이트 = 가장 최근 업데이트로 이름 · 설명 · 옵션이 바뀐 품목 · 포털 신규 = 최근 업데이트에서 새로 생긴 품목 · 단종 = 포털 목록에서 빠진 품목
    • 
        
  • ▾ 가 붙은 표시를 누르면 해당 품목 목록(Part No · 이름 · 구분 · 바뀐 내용)이 뜬다 — 카드는 열리지 않는다.

3 지원 규격 칩 읽는 법

      
본체를 고르면 Product Determinator 기준 지원 규격이 칩으로 나온다. 칩 색이 뜻하는 것:

      

        
802.11a/b/g/n/p · 본체 포함본체 포함 — 본체 설명에 이미 포함. 따로 살 필요 없음 (설명 기준 추정, 영업팀 확인 중)

        
802.11ax (Wi-Fi 6/6E)라이선스 — 라이선스를 사야 켜진다

        
True MIMO하드웨어 기본 — 라이선스 없음. 칩셋 자동 시험 SW(IQfact+)는 필요할 수 있음

        
GPS · C/N 시험만조건부 — C/N testing only · Stacked(테스터 결합) · 868/915 MHz만 · 시그널링 (Determinator 범례)

      

      
    
        
  • 칩을 누르면 802.11ax (Wi-Fi 6/6E) 처럼 ✓ 진한 색이 되고, 아래 선택 규격의 옵션에 그 규격의 품목이 나온다. 다시 누르면 해제.
    • 
        
  • 동시에 그 규격의 신규 구매 라이선스가 선택 목록에 담기고 표에서도 ☑ 된다. 본체 포함 · 하드웨어 기본은 담지 않고 이유가 잠깐 뜬다.
    • 
        
  • 전체 선택 / 전체 해제 — 모든 규격을 한 번에. 지원 규격 · 선택 규격의 옵션 카드는 제목을 눌러 접을 수 있다.
    • 
        
  • 하드웨어 기본(파랑) 칩을 누르면 그 기술에 쓰는 IQfact+ 품목(1 Tester · Full Site · 유지보수)도 함께 보여 준다.
    • 
        
  • 지원 규격 표(Determinator)에 없는 본체는 규격 조건 검색에서 확인 필요로 보고 맞음으로 치지 않는다.
    •

5 선택 목록

      
    
        
  • 품목 이름(QP 는 Part No) 앞 ☐ 체크 → 화면 아래 선택 목록 바에 담긴다. 담은 행은 청록 바탕.
    • 
        
  • 본체 · 본품 보기와 규격 칩으로도 자동으로 담긴다 (위 2 · 3).
    • 
        
  • 선택 목록은 한 번에 한 본체 · 본품 구성 — 다른 본체(또는 LP ↔ QP)로 바꾸면 묻지 않고 새로 시작한다.
    • 
        
  • 목록 을 누르면 품목별 카드 — − 수량 +, ✕ 빼기. 비우기 = 모두 지우기.
    • 
        
  • PC: ⮕ 세로 보기 = 선택 목록을 내용 바로 오른쪽 세로 패널로 (공간이 모자라면 화면 오른쪽 끝), ⬇ 아래 보기 = 화면 아래로. 폰은 항상 아래.
    • 
        
  • 목록은 이 기기 브라우저에 기억된다 (새로고침해도 남음, 가격은 저장하지 않음).
    • 
      

    


    

      
6 가격 · 합계 · 할인 영업 전용

      
    
        
  • 영업 계정은 로그인하면 ☑ 가격 포함이 켜져 있다 → 표 오른쪽에 정가 (USD). 끄면 그 화면에서만 숨김.
    • 
        
  • 옵션 가격은 선택한 본체 기준. 그 본체 기준 가격이 없으면 같은 품목의 다른 본체 가격을 ≈ 참고로 보인다.
    • 
        
  • 선택 목록 바: 합계 USD + ≈ 원화(오늘 환율, 기준일 · 출처 표시). 가격 없는 품목은 합계에서 빠지고 개수가 표시된다.
    • 
        
  • 할인 [ ]% 에 할인율을 넣으면 합계 · 원화가 할인 후 금액으로 바뀌고, 아래에 정가와 할인액이 나온다 (예: 정가 USD 94,000 · 할인 10% (−9,400)). 비우면 정가. 할인율은 기기에 기억. 품목별 금액은 정가 그대로.
    • 
        
  • 세금 · 운송 제외. 견적 발행 기능은 추후 검토.
    •

  • 엑셀 파일 암호를 바꾸면 이 PC 의 기준 엑셀도 새 암호로 다시 잠근다. 전에 나눠 준 엑셀은 옛 암호 그대로.

  • 현재 암호 보기 — 관리자 암호를 다시 넣으면 네 암호를 보여 준다 (이 PC 에서만, 보여 준 뒤 바로 지움). 관리자 암호를 막 바꿨다면 새로고침 후 새 암호로.
