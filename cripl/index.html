VSA Reference Level

          

          

        

        

          
변조별 전형 PAR

          

        

        

          PAR 를 잘못 잡으면
          · 너무 작게 → 피크가 ADC 상한 초과 → 클리핑 → EVM 악화, 파워 낮게 측정
          · 너무 크게 → ADC 동적범위 낭비 → 측정 SNR 저하 → EVM 바닥값 상승
          실측 PAR (Peak − Power) 를 재서 설정값과 1~2 dB 안에 있는지 확인하는 것이 가장 확실하다.

          파일은 어디로도 전송되지 않는다
          브라우저 안에서 헤더 앞부분만 잘라 읽는다. 수백 MB 파일도 즉시 처리되고 IQ 데이터는 건드리지 않는다.
        

        

          값이 없을 때
          N/A 그 규격에는 있는 항목인데 헤더에 기록이 없다 (구형 펌웨어가 안 남긴 경우)
          XXX 그 규격·모듈에 애초에 해당 없는 항목 (11ac 파일의 HE 항목, WLAN 파일의 BT 항목 등)
          값이 하나라도 있으면 언제나 값을 그대로 보여준다.
        

        

          표시 항목 (11그룹 165개)
          파일 · 신호 · WLAN 공통 · HE/EHT · DSSS/CCK
          필터/윈도우 · 패킷 · MAC 헤더
          Degradation(WaveGen GUI 순서) · Bluetooth · UWB
        

        

          비교 모드
          다른 값은 노란 배경으로 표시하고, 그룹 머리에 차이 개수를 붙인다.
          목록에서 클릭 = A, Shift+클릭 = B.
          원본 SCPI 차이 버튼은 위 164개 밖의 명령까지 전부 비교한다.
        

        

          N/A 가 정상인 경우
          WaveGen GUI 의 Phase Noise · AWGN SNR · IQ Gain/Phase/Delay · DCI/DCQ · SFactor · Channel Gain/Phase 는 생성 시점에만 적용되고 .iqvsg 헤더에 저장되지 않는다.
          2008~2012 년 .mod 변환 BT 파일에는 ModuleConfiguration 자체가 없다.

          확인 전
        

        
PC 프로그램 — 장비에 직접 연결중계 프로그램 없이 이 프로그램이 장비(SCPI TCP)에 바로 붙는다 (CAST 와 같은 방식).

        

        

        
중계 프로그램 — 휴대폰 · 웹 브라우저용

        

          
          
        

        

          
          
          확인 전
        

        

          중계 프로그램이 켜져 있어야 동작한다
          브라우저는 장비 소켓에 직접 붙지 못하므로 같은 폴더의 rf_bridge.py 가 대신 연결한다.
          · PC: RF중계.exe 실행 (또는 [중계 실행]) → 마지막에 쓴 장비에 연결해 두고 이 계산기가 열린다. Python 필요 없음
          · [중계 실행] 은 RF중계.exe 를 한 번이라도 실행한 PC 에서 동작한다 (그때 rfbridge:// 주소가 등록됨)
          · 안드로이드폰: RF 중계 앱 설치 → 앱 실행 (또는 [중계 실행]) → 중계 주소는 http://localhost:8765 그대로. PC 필요 없음, 폰이 테스터와 같은 Wi-Fi 에 있어야 함
          · 앱 없이 휴대폰: PC 에서 「RF 중계 (휴대폰도 연결)」 실행 → 중계 창에 나온 http://PC-IP:8765 를 휴대폰 브라우저로 연다 (github 주소에서는 PC 로 가는 요청이 막힘)
        

        


        

          포트
          LitePoint IQxel 계열은 보통 24000, Keysight · R&S 는 보통 5025. 장비 설정에서 확인.

        1. 로그인 · 앱 설치2. LP 제품 찾기3. 지원 규격 칩4. QP 제품
        5. 선택 목록6. 가격 · 합계 (영업)7. 엑셀 받기8. 알아 둘 점

2 LP 제품 찾기 LP 제품 열기 ›

      
    
        
  1. 제품 라인을 고른다 — 첫 화면 카드의 품목 N개 보기 또는 위쪽 제품 라인 콤보.
    2. 
        
  2. ① 제품(본체) 선택에서 본체의 ◉ 보기를 누른다. 본체는 모델 · 포트 순 (예: M2X → M8X → M16X).
          
    → 그 본체가 선택 목록에 자동으로 담긴다. 다른 본체로 바꾸면 선택 목록을 비우고 새 본체로 새로 시작한다.
    3. 
        
  3. 바로 아래에 지원 규격 카드와 ② 그 본체에 붙는 품목(HW · SW · Service)이 나온다.
    4. 
      

      
조건으로 거르기 — 표준 규격 · 최고 주파수 · 신호 대역폭 · RF 포트 수 · MIMO 를 넣으면 맞는 라인 · 본체만 남는다.

      
✔ 조건 맞음✕ 조건 불일치: 포트 8카드 왼쪽 줄 — 초록 = 맞음, 빨강 = 안 맞음 (「숨긴 것도 보기」로 안 맞는 것도 표시)

      
표 위 체크: 기본 설명 · 상세 설명(포털 영문 설명) · 구분 보기 · Part No 보기

    


    

      
3 지원 규격 칩 읽는 법

      
본체를 고르면 Product Determinator 기준 지원 규격이 칩으로 나온다. 칩 색이 뜻하는 것:

      

        
802.11a/b/g/n/p · 본체 포함본체 포함 — 본체 설명에 이미 포함. 따로 살 필요 없음 (설명 기준 추정, 영업팀 확인 중)

        
802.11ax (Wi-Fi 6/6E)라이선스 — 라이선스를 사야 켜진다

        
True MIMO하드웨어 기본 — 라이선스 없음. 칩셋 자동 시험 SW(IQfact+)는 필요할 수 있음

        
GPS · C/N 시험만조건부 — C/N testing only · Stacked(테스터 결합) · 868/915 MHz만 · 시그널링 (Determinator 범례)

      

      
    
        
  • 칩을 누르면 802.11ax (Wi-Fi 6/6E) 처럼 ✓ 진한 색이 되고, 아래 선택 규격의 옵션에 그 규격의 품목이 나온다. 다시 누르면 해제.
    • 
        
  • 동시에 그 규격의 대표 라이선스(신규 구매용 우선)가 선택 목록에 담긴다. 본체 포함 · 하드웨어 기본은 담지 않고 아래에 이유가 잠깐 뜬다.
    • 
        
  • 전체 선택 / 전체 해제 — 모든 규격을 한 번에. 선택 규격의 옵션 카드는 제목을 눌러 접을 수 있다.
    • 
        
  • 하드웨어 기본(파랑) 칩을 누르면 그 기술에 쓰는 IQfact+ 품목(1 Tester · Full Site · 유지보수)도 함께 보여 준다.
    •

5 선택 목록

      
    
        
  • 품목 이름(QP 는 Part No) 앞 ☐ 체크 → 화면 아래 선택 목록 바에 담긴다. 담은 행은 청록 바탕.
    • 
        
  • 본체 보기 · 규격 칩으로도 자동으로 담긴다 (위 2 · 3).
    • 
        
  • 목록 을 누르면 품목별 카드 — − 수량 +, ✕ 빼기. 비우기 = 모두 지우기.
    • 
        
  • 목록은 이 기기 브라우저에 기억된다 (새로고침해도 남음, 가격은 저장하지 않음).
    • 
      

    


    

      
6 가격 · 합계 영업 전용

      
    
        
  • 영업 계정은 로그인하면 ☑ 가격 포함이 켜져 있다 → 표 오른쪽에 정가 (USD). 끄면 그 화면에서만 숨김.
    • 
        
  • 옵션 가격은 고른 본체 기준. 그 본체 기준 가격이 없으면 같은 품목의 다른 본체 가격을 ≈ 참고로 보인다.
    • 
        
  • 선택 목록 바: 합계 USD + ≈ 원화(오늘 환율, 기준일 · 출처 표시). 가격 없는 품목은 합계에서 빠지고 개수가 표시된다.
    • 
        
  • 정가(List Price) 기준 — 할인 · 세금 · 운송 제외. 견적 발행 기능은 추후 검토.

8 알아 둘 점

      
    
        
  • 본체 포함(회색)은 포털 본체 설명으로 판단한 것 — 실제 출하 구성과 다르면 알려 줄 것.
